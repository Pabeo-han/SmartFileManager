# Smart File Manager
Windows / Python 3.14 / Tkinter. 외부 라이브러리 없이 실행: python main.py
EXE 제작: build.bat 실행 (인터넷 및 Python 필요). 결과: dist/SmartFileManager.exe
파일 정리는 선택 폴더 바로 아래만, 중복 검사는 하위 폴더까지 수행합니다.
중복은 크기 및 SHA-256으로 비교합니다. 격리 폴더는 검사에서 제외됩니다.
파일 이동은 덮어쓰기를 방지하기 위해 하드 링크를 사용합니다. NTFS 등 지원 파일시스템이 필요하며 미지원 환경에서는 이동에 실패합니다.
작업 기록 및 되돌리기는 프로그램 실행 중에만 유지됩니다. 격리 파일은 직접 복구할 수도 있습니다.
실제 중요 파일이 아닌 테스트 폴더에서 먼저 확인하세요.
