# Smart File Manager

파일 자동 정리 및 중복 파일 탐지 프로그램

## 1. 프로젝트 소개

Smart File Manager는 여러 종류의 파일이 섞여 있는 폴더를 자동으로
정리하고, 내용이 동일한 중복 파일을 찾아 관리할 수 있는 Windows GUI
프로그램입니다. Python과 Tkinter를 활용하여 별도의 명령어 입력 없이
파일을 관리할 수 있도록 개발하였습니다.

## 2. 개발 목적

- 파일을 종류별로 자동 분류하여 정리 시간을 단축합니다.
- 파일 이름이 아닌 실제 내용을 비교하여 중복 파일을 탐지합니다.
- 격리 및 작업 복구 기능을 통해 파일 관리 과정의 실수를 줄입니다.

## 3. 주요 기능

| 기능              | 설명                                                                      |
|-------------------|---------------------------------------------------------------------------|
| 파일 분석         | 전체 파일 개수, 용량 및 중복 후보 표시                                    |
| 파일 자동 정리    | 확장자에 따라 이미지, 동영상, 문서, 음악, 압축파일, 프로그램, 기타로 분류 |
| 정리 미리보기     | 이동 예정 파일명, 분류 및 용량 확인                                       |
| 중복 파일 탐지    | 파일 크기와 SHA-256 해시값 비교                                           |
| 중복 파일 격리    | 선택한 중복 후보를 별도 폴더로 이동                                       |
| 작업 기록 및 복구 | 파일 이동 결과 확인 및 작업 되돌리기                                      |

## 4. 개발 환경

| 항목              | 사용 기술         |
|-------------------|-------------------|
| 운영체제          | Windows           |
| 개발 언어         | Python 3.14       |
| GUI               | Tkinter, ttk      |
| 파일 및 경로 관리 | os, pathlib       |
| 중복 파일 검사    | hashlib (SHA-256) |
| 백그라운드 검사   | threading, queue  |
| 실행파일 제작     | PyInstaller       |
| 데이터베이스      | 사용하지 않음     |

``` text
├── build.bat     # Windows 실행파일 제작 스크립트
└── README.md     # 프로젝트 설명서
```

## 6. 실행 방법

### 소스코드 실행

Python이 설치된 Windows 환경에서 프로젝트 폴더를 열고 다음 명령어를
실행합니다. 프로그램 실행에는 별도의 외부 Python 라이브러리가 필요하지
않습니다.

``` cmd
python main.py
```

### Windows 실행파일 제작

`build.bat`을 실행하거나 아래 명령어를 입력합니다. PyInstaller 설치에는
인터넷 연결이 필요할 수 있습니다.

``` cmd
python -m pip install pyinstaller
python -m PyInstaller --onefile --windowed --name SmartFileManager main.py
```

생성된 실행파일: `dist/SmartFileManager.exe`

## 7. 사용 방법

1.  관리할 폴더를 선택합니다.
2.  파일 분석 결과를 확인합니다.
3.  파일 정리 탭에서 이동 예정 목록을 확인하고 정리를 실행합니다.
4.  중복 파일 탐지 탭에서 격리할 파일을 선택합니다.
5.  작업 기록에서 처리 결과를 확인하고 필요하면 작업을 되돌립니다.

## 8. 구현 원리 및 주의사항

- 파일 정리는 선택한 폴더 바로 아래의 파일만 대상으로 하며, 중복 검사는
  하위 폴더까지 수행합니다.
- 크기가 같은 파일의 SHA-256 해시값을 비교하여 중복 후보를 찾습니다.
- 중복 파일은 `_중복파일_격리` 폴더로 이동하며 영구 삭제하지 않습니다.
  해당 폴더는 검사에서 제외됩니다.
- 동일한 이름의 파일이 있으면 새로운 이름을 부여하여 덮어쓰기를
  방지합니다. 파일 이동에는 하드 링크를 사용하므로 NTFS 등 이를 지원하는
  파일시스템이 필요합니다.
- 작업 기록과 자동 복구 목록은 프로그램 실행 중에만 유지됩니다. 종료
  후에는 필요에 따라 파일을 직접 복구해야 합니다.
- 실제 중요 파일을 관리하기 전에 테스트 폴더에서 사용해 보는 것을
  권장합니다.

## 9. 기대 효과

파일 관리에 필요한 반복 작업을 줄이고 저장 공간을 효율적으로 관리할 수
있습니다. 또한 본 프로젝트를 통해 Python의 GUI 구성, 이벤트 처리, 파일
입출력, 해시 비교, 예외 처리 및 실행파일 제작 방법을 학습할 수 있습니다.
